# Book entity SEO

The authored book «تشخیص، فرمول‌بندی و طرح درمان شناختی–رفتاری اختلال اضطراب فراگیر» is treated as a `schema.org/Book` entity in the site's publication metadata.

This is an entity-completeness improvement, not a new user-facing feature. The implementation should expose only verified metadata and link the author to the site's stable Person entity.

Google's Book structured-data documentation distinguishes a Book work from its editions and uses ISBN as an important reconciliation signal. The project does **not** implement Google's Book Actions/DataFeed because this personal site is not a broad book provider and does not currently meet that product's provider model.

Reference: https://developers.google.com/search/docs/appearance/structured-data/book
